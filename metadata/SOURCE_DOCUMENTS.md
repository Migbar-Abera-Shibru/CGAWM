# Source documents used for provenance review

The following source documents were used during the current reconciliation of the CGAWM revision package:

- CGAWM manuscript prepared for Scientific Reports.
- `Thesis_Migbar.pdf` — master's thesis containing the experimental setup, hyperparameters, ablation table, long-run three-seed results, and SOTA comparison table.
- `new_seed_experiment.ipynb` — preserved 5,000-episode experiment with seeds 42, 123, and 999.
- `Improve_the_CGAWM.ipynb` — preserved ablation/development notebook with multiple executions.
- `comparison_on_SOTA.ipynb` — preserved SOTA comparison notebook.
- `new_test_for_sota.ipynb` — later SOTA notebook containing 5,000-episode runs and the exact Figure 7 plotting values.
- `Untitled23.ipynb` — separate exploratory research suite with different seeds/experimental logic.
- `wandb_experiment_export.csv` — exported W&B run data available during the current recovery.

The thesis and manuscript PDFs are not duplicated inside this package. Their purpose here is provenance/reconciliation; the public repository should contain the documents only if the authors decide that publication of those documents is appropriate.
